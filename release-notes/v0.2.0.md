# Verstak Official Plugins v0.2.0

## Обслуживание

- Настройки синхронизации, индикатор синхронизации в строке состояния и мастер импорта собраны на Svelte 5 и Vite 8. Поведение не меняется; обновление закрывает известные уязвимости инструментов сборки.
- Номер версии перепрыгивает на v0.2.0: старые служебные теги v0.1.7–v0.1.9 от августа по номеру были выше v0.1.4 и v0.1.5, и всё, что выбирало «самый новый тег плагинов», получало августовский код. Публикация теперь отказывается выпускать версию ниже уже существующей.

## Maintenance

- Sync settings, the sync status bar indicator and the import wizard are built with Svelte 5 and Vite 8. Behaviour is unchanged; the upgrade closes known vulnerabilities in the build tooling.
- The version jumps to v0.2.0: stray v0.1.7–v0.1.9 tags from August sorted above v0.1.4 and v0.1.5, so anything picking "the newest plugins tag" got August code. Publishing now refuses a version lower than an existing one.
