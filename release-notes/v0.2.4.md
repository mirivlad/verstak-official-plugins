# Verstak Official Plugins v0.2.4 — Секреты в заметках

Совместимый выпуск приложения: **Verstak v0.3.1**.

- «Забыли мастер-пароль?» сохраняет старое зашифрованное хранилище в архиве и позволяет создать новое. Для чтения архива по-прежнему нужен старый пароль.
- Кнопка с ключом в Markdown-редакторе вставляет ссылку на секрет текущего Дела или общий секрет. Выделенный текст становится подписью; значения секретов не записываются в заметку.
- Нажатие на ссылку открывает окно поверх заметки. После однократной разблокировки логин и значение можно выделить или скопировать кнопками.
- «Изменить» открывает поля в том же окне. Сохранение сохраняет ID и привязку к Делу; ошибка записи не стирает введённые данные.
- Мастер-пароль принимается по Enter и запрашивается один раз до завершения приложения или переоткрытия/смены хранилища.
- Исправлена доступность кнопок копирования; новые секреты без явно заданного ID получают уникальный ID.

## English

- Pair this plugin set with Verstak v0.3.1.
- Archive the complete encrypted store before starting fresh after a forgotten master password; the archive still requires the old password.
- Insert links to current-Deal or shared secrets, preserving selected note text as the label and keeping values out of Markdown.
- View, copy and edit credentials in a dialog above the note, with one unlock per application/vault session.
- Preserve record identity, Deal scope and edited fields on write failures; support Enter to unlock and usable copy buttons.
