# Verstak Official Plugins v0.2.2

## Синхронизация

- Исправлено вводящее в заблуждение сообщение об ошибке авторизации: сервер может отклонить логин и пароль, не отзывая устройство.
- Теперь сообщение подсказывает проверить учётные данные или привязку устройства.

## Synchronization

- Clarify HTTP 401 authorization failures. A rejected username or password does not necessarily mean the device has been revoked.
- Suggest checking credentials or the device pairing.
