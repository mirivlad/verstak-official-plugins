# Verstak Official Plugins v0.2.7 — Последний черновик редактора

Совместимый выпуск приложения: **Verstak v0.3.3**.

- При закрытии редактор передаёт оболочке завершение очереди записей черновика.
- Последняя правка сохраняется и при уходе до срабатывания таймера, и при незавершённой предыдущей записи.
- Переоткрытие восстанавливает черновик; исходный файл по-прежнему сохраняется отдельным действием.

## English

- Return the final draft-write completion to the host on editor unmount.
- Preserve the latest unsaved edit on rapid navigation and while an earlier draft write is pending.
- Restore the draft on reopening without implicitly saving the underlying file.
