## Highlights

- Plugins say what belongs on a Deal's first screen. Overview used to be assembled by the shell reaching into the storage of specific official plugins and knowing what their keys meant, which left no way for any other plugin to appear there. Each plugin now declares its own Overview contributions — what to resume, what needs attention, what changed — and the shell shows what it is given.
- Search belongs to the domain that owns the data. Notes, Files, Journal, Todo and Browser captures each provide their own Search results, with their own labels and their own way of opening what was found. A folder result opens the folder rather than offering an action that does nothing.
- `verstak.folder-appearance` is retired. It duplicated the picker the application already had and declared a contribution point the runtime never supported. Colours and icons set through it are migrated by the application on first read; nothing needs to be re-chosen.
- A package declares the stylesheets it ships, and the build refuses a package whose declared frontend assets are not there.

## Главное

- Плагины сами говорят, что относится к первому экрану Дела. Overview собирала оболочка, залезая в хранилище конкретных официальных плагинов и зная, что значат их ключи, — попасть туда любому другому плагину было нельзя. Теперь каждый плагин объявляет свои вклады в Overview: к чему вернуться, что требует внимания, что изменилось, — а оболочка показывает то, что ей дали.
- Поиск принадлежит той области, которой принадлежат данные. Заметки, Файлы, Журнал, Задачи и захваты браузера дают собственные результаты поиска, со своими подписями и своим способом открыть найденное. Найденная папка открывается, а не предлагает действие, которое ничего не делает.
- `verstak.folder-appearance` выведен из состава. Он дублировал выбор, который в приложении уже был, и объявлял точку вклада, никогда не поддерживавшуюся рантаймом. Цвета и иконки, заданные через него, приложение переносит при первом чтении — выбирать заново ничего не нужно.
- Пакет объявляет стили, которые везёт, и сборка не пропускает пакет, у которого объявленные frontend-ассеты отсутствуют.

## Compatibility / Совместимость

Требует Verstak v0.1.3. Провайдеры Overview и Поиска — контракты SDK, которые более ранняя оболочка не потребляет.

Requires Verstak v0.1.3. The Overview and Search providers are SDK contracts an earlier shell does not consume.
