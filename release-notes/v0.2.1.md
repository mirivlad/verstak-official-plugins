# Verstak Official Plugins v0.2.1

## Редактор заметок

- Компактные SVG-иконки с локализованными подсказками вместо текстовых кнопок. Панели не занимают лишних строк в узком окне.
- Прикрепление изображений и файлов через скрепку, перетаскивание и вставку из буфера обмена. Вложения сохраняются локально рядом с заметкой, без перезаписи одноимённых файлов; предел 8 МиБ на файл.
- Просмотр вложенных изображений и открытие файлов из режима чтения.
- Редактирование существующих ссылок, не создающее вложенных ссылок.
- Горячие клавиши: Ctrl+S — сохранить, F2 — переименовать, Ctrl+E — чтение/редактирование, Ctrl+Shift+E — режим рядом. Добавлены клавиши форматирования списков и встроенная справка.
- Переименование сохраняет прежний заголовок как alias, чтобы ссылки из других заметок продолжали работать. Конфликты имён и ошибки сохранения обрабатываются безопасно.
- Парные скобки и кавычки, всплывающая панель форматирования выделенного текста.

## Notes editor

- Compact icon-only toolbars with localized tooltips and responsive horizontal scrolling.
- Vault-local file and image attachments via picker, drag-and-drop, and paste; collision-safe naming and an 8 MiB per-file limit.
- Embedded image preview and attachment opening in reading mode; edit existing links.
- Save, rename, edit/preview, split-view and list-formatting keyboard shortcuts with an in-editor shortcut reference.
- Rename safely preserves old note titles as aliases, so incoming wiki links continue resolving.
- Automatic paired brackets and quotes and contextual selection formatting.
