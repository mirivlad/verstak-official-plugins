# Verstak Official Plugins v0.1.5

## Редактор заметок

- Редактирование, чтение и режим «Рядом» с общей историей изменений и сохранением позиции.
- Ctrl+Z, Ctrl+Y и Ctrl+Shift+Z работают для текста, форматирования, ссылок и задач, в том числе в русской раскладке.
- Ссылка на заметку: кнопка «Ссылка на заметку», Ctrl+K или ввод `[[` с выбором из списка. Можно явно создать новую заметку. Прежние имена продолжают открывать переименованные заметки.
- Крупные интерактивные задачи в просмотре: отметка меняет соответствующий Markdown и сохраняет файл. Лишние маркеры списка убраны.
- В чтении скрыта панель форматирования. Добавлены читаемая вёрстка, оглавление, контекст обратных ссылок, подсветка и копирование блоков кода.
- Отмена форматирования, продолжение списков по Enter, поиск и замена. Черновики восстанавливаются после закрытия; внешний конфликт файла не перезаписывается молча.

## Notes editor

CodeMirror-based editing with persistent undo history, reading and split modes, note-link completion/picker, interactive GFM tasks, syntax-highlighted code, draft recovery and external-change warnings. Markdown files and existing note aliases remain compatible.
