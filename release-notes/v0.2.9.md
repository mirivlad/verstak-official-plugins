# Verstak Official Plugins v0.2.9 — Действия 2.0

Совместимый выпуск приложения: **Verstak v0.3.5**.

- Новый плагин `verstak.actions`: общий раздел и вкладка Дела, создание, редактирование, удаление и порядок действий.
- Компактные карточки запускают программы, явно указанные интерпретаторы со скриптами и HTTP(S)-ссылки. Консольные команды показывают результат и поддерживают остановку.
- Общий поиск иконок, обычная строка аргументов с кавычками, управление при наведении и с клавиатуры, светлая/тёмная темы и RU/EN.
- Сохранение через форму выдаёт доверие только на текущем устройстве. Внешние определения и изменения исполняемых параметров требуют подтверждения; импортированные поля `approved` и `trusted` не выдают доверия.
- Необязательный запрос перед каждым запуском. Постоянные предупреждения и отдельный отзыв разрешения удалены.
- Определения синхронизируются, локальное доверие — нет. Ни импорт, ни синхронизация, ни открытие приложения или Дела ничего не запускают автоматически.

Старые определения Actions 2.0 поддерживаются. Без локальной записи доверия потребуется одно подтверждение. Для новых API нужен Desktop v0.3.5; интеграция SSHKeeper в этот выпуск не входит.

## English

- Add Actions globally and within Deals, with compact launch cards, ordering, shared icon search, plain arguments, console output and cancellation.
- Trust form saves on the current device. Confirm imported or synced commands once and confirm external executable changes again; imported approval flags cannot grant trust.
- Offer optional confirmation before every run. Keep trust local, preserve existing definitions, and never execute automatically.
- Require Desktop v0.3.5 for the new APIs. SSHKeeper integration is not part of this release.
