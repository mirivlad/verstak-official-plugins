# Verstak Official Plugins v0.2.6 — Возвращение к заметкам

Совместимый выпуск приложения: **Verstak v0.3.2**.

- Обзор Дела предлагает до трёх последних изменённых заметок, используя время изменения файлов.
- Каждая карточка открывает свою заметку. Ресурс `Overview.md` также открывает указанный файл, а общий счётчик заметок ведёт к списку.
- Если заметку успели переместить или удалить, остаётся список заметок с понятным сообщением.
- Названия и время в карточках берутся из текущих файлов Дела; записи без корректной даты не выдаются за недавнюю работу.

## English

- Resume up to three recently modified notes from the Deal Overview.
- Open each note or named key resource directly; keep the total linked to the Notes list.
- Keep the Notes list and explain the failure if a linked file was moved or removed.
- Use actual file metadata and readable note titles.
