# Verstak Official Plugins v0.2.3

- Формы, списки и редактор следуют светлой/тёмной палитре оболочки Verstak v0.3.0.
- Основные действия используют индиго с белым текстом; обновлены стили чтения, редактирования и подсветки кода.
- При создании Дела старые рецепты освобождаются от устаревшего `verstak.activity`; остальные инструменты и пользовательские поля сохраняются. Недоступные инструменты перечисляются в понятной ошибке.

## English

- Follow the host light/dark appearance across official plugin surfaces and the Markdown editor.
- Use indigo primary actions with white labels and theme-aware preview, editing and code colors.
- Migrate the retired Activity Deal tool in stored templates while retaining custom fields and other tools; identify unavailable tools when creation cannot proceed.
