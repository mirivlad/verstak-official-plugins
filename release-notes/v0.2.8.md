# Verstak Official Plugins v0.2.8 — Ручное добавление материалов

Совместимый выпуск приложения: **Verstak v0.3.4**.

- Browser Inbox принимает ссылку HTTP(S), текст или оба поля через кнопку «Добавить материал».
- Глобальный раздел позволяет выбрать Дело; вкладка Дела использует текущее Дело.
- Введённое сохраняется при ошибке. Повтор отправки не создаёт дубликат; поступления из расширения не затираются.
- Светлая и тёмная темы, проверка адреса, управление клавиатурой и возврат фокуса.
- Очередь остаётся локальной для устройства; конвертированные заметки и файлы синхронизируются обычным способом.

На хостах до v0.3.4 без атомарного settings API ручное добавление скрыто.

## English

- Add HTTP(S) links, text or both without the browser extension.
- Choose a Deal globally or use the current Deal in its Browser tab.
- Preserve input on failure, avoid duplicates on retry and retain concurrent extension captures.
- Support both themes, URL validation, keyboard navigation and focus restoration.
- Keep the queue device-local; converted notes and files use normal sync.

Manual capture is hidden on older hosts without the atomic settings API.
