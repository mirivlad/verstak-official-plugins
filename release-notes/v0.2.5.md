# Verstak Official Plugins v0.2.5 — Создание секретов в Делах

Совместимый выпуск приложения: **Verstak v0.3.1**.

- Включает работу с секретами из v0.2.4: архивирование заблокированного хранилища, ссылки из заметок, просмотр, копирование и редактирование в окне с одной разблокировкой за сессию.
- Список Дел для нового секрета загружается сразу после первой разблокировки, в том числе после создания нового хранилища.
- Выбор Дела использует семантический список: вложенные Дела доступны, обычные организационные папки не предлагаются как Дела.
- Текущее Дело и привязки существующих записей сохраняются в выборе при временной недоступности списка.

## English

- Includes v0.2.4 secret links, archive/reset and in-place credential dialogs.
- Load Deal options immediately after the first unlock, including fresh stores.
- Include nested Deals and exclude organizational folders using the workspace API.
- Retain the current Deal and existing record scopes if the workspace list is unavailable.
